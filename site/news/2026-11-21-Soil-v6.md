We are happy to announce the availability of [Soil](https://github.com/ApptiveGrid/Soil) version 6.

spoiler: No migration is necessary from v5. The on-disk format is unchanged.

## What is new?

- **Soil now runs on Windows.** From now on Windows is officially supported and is here to stay.
- **Backup, read-only and recovery.** This was a side track to Windows support. Streams now get managed and closed better. Read-only support has been improved to really work the way intended.
- **New visitors and tracking:** There is a revamped infrastructure to traverse the whole database structure. There is a new tracking visitor that walks the heap and takes tracking objects as infrastructure. One application of that is to check consistency of the database. Further work is done to e.g. collect migratable objects.
- **And Residents:** This is the biggest change in the release. We introduced a system helping to circumvent problems like objects that need to live longer than a transaction and a database infrastructure to extend the database taking actively place in the application being built. And this an infrastructure future soil models can extend what a database can do for you. Read more: [https://norbert.hartl.name/blog/2026-11-19_soil-residents.html](https://norbert.hartl.name/blog/2026-11-19_soil-residents.html)

The more detailed view can be seen here: [https://github.com/ApptiveGrid/Soil/blob/main/docs/versions/changelog-v6.md](https://github.com/ApptiveGrid/Soil/blob/main/docs/versions/changelog-v6.md)

## What is planned next?

On the list for coming things there are:

- Multi-index collections and partial indexes (carried over from v4/v5)
- Finishing the online/24-7 garbage collector on top of the offline GC primitives
- Copy-on-write for index pages, so a transaction that only reads copies nothing

Hope you like it. Give it a spin and then tell us!
